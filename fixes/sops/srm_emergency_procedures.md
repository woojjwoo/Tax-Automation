# BLOCKER 6 FIX: SRM/MEV Emergency Procedures

**Post this document near the POS station.**

---

## If the SRM Stops Working

### Step 1: Don't panic. Don't shut down.

You can continue serving customers, but you MUST follow these steps.

### Step 2: Switch to backup SRM (if available)

1. Unplug the failed SRM unit
2. Connect the backup SRM unit (stored in office / under POS counter)
3. The backup SRM is pre-configured — it should connect automatically
4. Verify a test transaction produces a signed receipt
5. Resume normal operations

**If no backup SRM is available, go to Step 3.**

### Step 3: Manual bill production (temporary — max 48 hours)

While operating without SRM, every bill MUST include:
- [ ] Restaurant name and address
- [ ] GST registration number
- [ ] QST registration number
- [ ] Date and time of transaction
- [ ] Itemized list of goods/services
- [ ] GST amount (5%)
- [ ] QST amount (9.975%)
- [ ] Total amount
- [ ] Sequential bill number (start from M-001 for manual)
- [ ] Note: "MEV en panne — facture manuelle" (SRM out of service — manual bill)

### Step 4: Notify Revenu Québec

**Within 24 hours of the SRM failure:**

Call Revenu Québec business line: **1-800-567-4692**

Provide:
- Business name: Giwa Restaurant Inc.
- NEQ: [your number]
- QST number: [your number]
- SRM certificate number: [your number]
- Date and time SRM failed
- Reason (if known): hardware failure / power surge / software error
- Expected repair timeline

**Document the call:** date, time, agent name, reference number.

### Step 5: Record all transactions manually

During SRM downtime, keep a log:

| Bill # | Date/Time | Items | Subtotal | GST | QST | Total | Payment |
|--------|-----------|-------|----------|-----|-----|-------|---------|
| M-001  |           |       |          |     |     |       |         |
| M-002  |           |       |          |     |     |       |         |

### Step 6: Re-enter when SRM is restored

Once the SRM is repaired or replaced:
1. Enter all manual transactions into the POS/SRM
2. Verify totals match manual log
3. Keep manual bills as backup documentation
4. Note in monthly reconciliation: "SRM downtime [date] to [date]"

|-----------|---------|
