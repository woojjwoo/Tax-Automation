# BLOCKER 10 FIX: Loi 101 Language Configuration

**All software used by Giwa employees must be available in French.**

---

## Software Language Settings

### QuickBooks Online (QBO)
- **French available:** Yes
- **How to set:** Settings → Company → Language → Français (Canada)
- **Impact:** All menus, reports, and invoices in French
- **Status:** [ ] Configured

### Lightspeed Restaurant
- **French available:** Yes (Montreal-based company)
- **How to set:** Settings → General → Language → Français
- **Impact:** POS interface, receipts, back-office in French
- **Status:** [ ] Configured

### Dext (Receipt Bank)
- **French available:** Limited (interface mostly English, some French)
- **How to set:** Account Settings → Language → if available, select Français
- **Workaround:** Create a French-language visual guide for the mobile app
  (screenshot-based: "Take photo" → "Send" — 3 steps)
- **Staff impact:** Only owner uses Dext; servers do not interact with it
- **Status:** [ ] Configured or visual guide created

### Wagepoint
- **French available:** Yes
- **How to set:** Company Settings → Language → Français
- **Impact:** Pay stubs, employee portal in French
- **Status:** [ ] Configured

### TaxCycle
- **French available:** Yes (full bilingual support)
- **How to set:** Options → Language → Français
- **Impact:** Tax returns, schedules, worksheets in French
- **Status:** [ ] Configured
