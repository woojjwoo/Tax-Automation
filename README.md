# Tax-Automation: Giwa Restaurant — Quebec Year-End Compliance

Comprehensive tax compliance automation for **Giwa**, a Montreal-based restaurant,
covering T2 (Federal), CO-17 (Quebec), SRM/MEV reconciliation, and tip reporting credits.

## Repository Structure

```
├── checklists/
│   ├── year_end_compliance_checklist.md   # Master T2/CO-17 checklist
│   ├── srm_mev_reconciliation.md         # SRM/MEV mandatory reconciliation
│   └── tip_credit_pme_6_1.md            # Quebec Tax Credit for Reporting of Tips
├── workflows/
│   ├── automated_gst_qst_workflow.md     # Cloud accounting + Dext + Payroll pipeline
│   └── workflow_config.yaml              # Machine-readable workflow configuration
├── business_model/
│   └── tech_driven_cpa_firm.md           # Business model for Quebec SME market
└── README.md
```

## Applicable Legislation & Filing Deadlines

| Filing              | Deadline                          | Authority        |
|---------------------|-----------------------------------|------------------|
| T2 Corporate Return | 6 months after fiscal year-end    | CRA              |
| CO-17 Corporate Return | 6 months after fiscal year-end | Revenu Québec    |
| GST/HST Return      | Quarterly or annually             | CRA              |
| QST Return          | Quarterly or annually             | Revenu Québec    |
| T4/RL-1 Slips       | Last day of February              | CRA / RQ         |
| SRM/MEV Annual Reconciliation | With CO-17 filing        | Revenu Québec    |
